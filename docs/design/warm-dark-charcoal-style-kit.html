Warm-Dark "Charcoal" Theme

A dark theme that's actually readable — soft charcoal instead of pure black, off-white text, one warm gold accent, and desaturated status colors. This kit is dual-target: the :root block for web, and a matching theme.py block for tkinter / CustomTkinter apps (identical hex values). The tkinter values below are the battle-tested version — they were revised over several rounds because the original web palette didn't transfer cleanly to a native toolkit (no CSS cascade, different contrast math). Those lessons are in the last section.

The muted sage green (#7FB58C) replaced an earlier neon green (#7ED492): on charcoal the brighter one screamed. Desaturating status colors is the single change that made the palette feel intentional rather than default-dark.

Body text sits at #dcdce2 — slightly under primary ink so long passages are easy on the eyes.
Soft secondary text at --soft for supporting detail.

Pairing: Inter for everything human, JetBrains Mono for eyebrows, labels, and every number (phones, counts, codes). In tkinter the type scale is fixed to three steps — FS_SM 12 / FS_MD 13 / FS_LG 15 — plus a shared control height CTRL_H 30 so rows of buttons, dropdowns, and entries align. Hierarchy comes from weight + the three text tiers, not from boxing everything.

tkinter / CustomTkinter port — copy this, not the CSS

Drop these constants into a theme.py and apply them per-widget via fg_color=, text_color=, border_color=, hover_color=, font=. There is no cascade in Tk — every widget is styled explicitly, which is exactly why a token module (one source of truth) matters more here than on the web.

# ── Geometry ──
RADIUS = 3            # tight corner; Tk over-rounds, keep it small
CTRL_H = 30           # shared height: buttons=dropdowns=entries align

# ── Surfaces (never pure black; step UP from base) ──
BG_DEEP     = "#16161A"   # window bg
BG_PANEL    = "#212129"   # panels / cards / row rest
BG_PANEL_HI = "#262630"   # input fills · hover
BG_RECESSED = "#1E1E24"   # chips / recessed
SELECT_BG   = "#332B18"   # selected row (warm gold-tint)
BORDER      = "#34343F"   # 1px hairline
BORDER_HI   = "#4A4A57"

# ── Text (off-white, three tiers — never #FFF) ──
TEXT = "#F1F1F4";  TEXT_DIM = "#B9B9C4";  TEXT_MUTE = "#7D7D8A"

# ── Brand: the ONE warm accent ──
BRAND = "#E7B94E";  BRAND_HI = "#F2C963";  BRAND_DIM = "#A8862F"

# ── Secondary "outlined ghost" button ──
BTN_FILL = "#2E2E3A";  BTN_FILL_HI = "#3A3A48"
BTN_EDGE = "#585866";  BTN_EDGE_HI = "#C79A3A"  # hover warms → gold

# ── Status (DESATURATED) ──
OK   = "#7FB58C";  OK_HI = "#94C4A0"   # muted sage (not neon)
WARN = "#F0B562";  FAIL  = "#EF8A8A";  FAIL_HI = "#F4A0A0"
INFO = "#6CC4E8";  PURPLE = "#B99CE8";  NEUTRAL = "#9A9AA6"

# ── Type scale + font fallback chains (Tk needs real installed names) ──
FS_SM, FS_MD, FS_LG = 12, 13, 15
MONO = ("JetBrains Mono", "Cascadia Mono", "SF Mono", "Menlo", "Consolas")
SANS = ("Inter", "Segoe UI Variable", "SF Pro Display", "Segoe UI")

# Button roles — DARK ink on the colored fill (the key transfer fix):
#   primary  → fg=BRAND, text="#231A05"   (dark warm ink on gold)
#   positive → fg=OK,    text="#0C2114"
#   danger   → fg=FAIL,  text="#170808"
#   secondary→ fg=BTN_FILL, text=TEXT, border=BTN_EDGE, +hover_border()

Why it works — and what didn't transfer to tkinter

  • Never pure black. Base is soft charcoal #16161A; surfaces step up (#212129 → #262630). Pure #000 flattens depth and over-sharpens contrast.
  • Off-white, not white. Text is #F1F1F4; full #FFFFFF on dark vibrates and tires the eye.
  • One warm accent. Gold carries emphasis everywhere; resist a second accent — restraint is the look.
  • Desaturated status colors. Muted sage/red/blue read clearly on charcoal; saturated ones scream and cheapen it. The neon-green → sage swap was the biggest single upgrade.
  • Three text tiers. ink / soft / dim create hierarchy through type, so you box less and the layout breathes.
  • Layered surfaces + hairline borders. Depth comes from subtle value steps and 1px lines, not shadows — and Tk has no real shadow anyway, so this port is naturally faithful.
  • Dark ink on colored fills. The web instinct is light text on a colored button. On these light-ish gold/green/red fills that reads as faint near-white mush — pin a dark text color per role (#231A05 on gold). This was the #1 thing that "didn't transfer."
  • No cascade — style every widget. CSS inheritance does not exist in Tk; a token module is the substitute. Apply fg_color/text_color/border_color explicitly and pull every value from one theme.py.
  • Hover-border by bind. CustomTkinter has no hover_border_color. Warm the secondary hairline toward gold with an <Enter>/<Leave> bind — the micro-interaction that makes quiet buttons feel deliberate.
  • Pin the disabled text color. Tk dims the fill but keeps text color on disable, leaving unreadable light text on a light fill. Set text_color_disabled (dark for filled roles, muted gray for ghosts).
  • Fixed control height + real font fallbacks. Share one CTRL_H so control rows align, and give fonts an installed-name fallback chain (Tk silently substitutes an ugly default if the exact name is missing).
